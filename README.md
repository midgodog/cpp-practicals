# C++ Programming Practicals

This repository contains 11 C++ programming practicals covering fundamental programming concepts, object-oriented programming, STL, design patterns, templates, exception handling, and file handling.

## Practicals

| No. | Practical | Concepts |
|---|---|---|
| 01 | GitHub Setup and C++ Fundamentals | Data types, variables, operators, input/output |
| 02 | Classes and Access Specifiers | Classes, objects, encapsulation |
| 03 | Constructors and Rule of Five | Copy/move constructors, memory management |
| 04 | RAII and Smart Pointers | `unique_ptr`, `shared_ptr`, RAII |
| 05 | Single and Multilevel Inheritance | Inheritance, derived classes |
| 06 | Runtime Polymorphism | Abstract classes, virtual functions |
| 07 | Compile-Time Polymorphism | Function and operator overloading |
| 08 | Factory Design Pattern | Factory pattern, object creation |
| 09 | Generic Stack Using Templates | Templates, STL, exception handling |
| 10 | Custom Exceptions | Exception handling, banking transactions |
| 11 | CSV Student Records | File handling, `fstream`, file positions |

## Requirements

- C++ compiler (G++ recommended)
- Visual Studio Code (recommended)
- Git

## How to Compile and Run

Open the terminal in the project folder and compile a practical:

```bash
g++ -std=c++17 Practical_01.cpp -o practical
```

Run it:

**Windows:**
```bash
.\practical.exe
```

**Linux/macOS:**
```bash
./practical
```

Replace `Practical_01.cpp` with the required practical filename.
